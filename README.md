# Idfan Winata — Portfolio Starter

Responsive static website portfolio for Technical Support, Application Support, Training & Development, Data Analytics, and AI Automation.

## Files
- `index.html`: content and project cards
- `style.css`: responsive design
- `script.js`: current year and placeholder links

## Preview locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish free
### GitHub Pages
1. Create a public GitHub repository, e.g. `idfan-portfolio`.
2. Upload all files to the repository root.
3. Open repository **Settings → Pages**.
4. Select deployment from the `main` branch and root folder.

### Render Static Site
1. Push this folder to GitHub.
2. In Render choose **New → Static Site** and connect the repository.
3. No build command is required; use `.` as the publish directory.

## Before publishing
- Replace `YOUR_EMAIL@example.com` and profile/project links.
- Verify experience duration and job titles against your CV.
- Mark projects honestly as completed, in progress, or planned.
- Add real screenshots and repository links.
- Never publish company-confidential data, employee records, credentials, or internal logs.
- Keep only skills you can demonstrate in an interview.
